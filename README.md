# 🩺 «Подручный Доктор» (Evidence-Based Medical AI)

Интеллектуальная веб-система скорой и клинической помощи на основе принципов **Доказательной Медицины (Evidence-Based Medicine, EBM)**, протоколов Всемирной организации здравоохранения (ВОЗ), Европейского совета по реанимации (ERC/AHA), клинических рекомендаций и мета-анализов Cochrane / PubMed.

---

## 🌟 Ключевые возможности

1. **🎙️ Голосовой ввод в реальном времени (Web Speech API)**
   - Нажмите на большую светящуюся иконку микрофона и опишите свои симптомы голосом.
   - Живая потоковая транскрипция речи на русском языке (`ru-RU`) прямо во время говорения.
   - Синтез речи (TTS) — возможность прослушивания рекомендаций доктора вслух (режим «hands-free», когда руки заняты первой помощью).

2. **⚡ Мгновенный триаж и распознавание жизнеугрожающих состояний (Red Flags)**
   - Автоматический скрининг симптомов за <2 мс:
     - Остановка дыхания и сердца ➔ протокол СЛР 30:2
     - Инсульт ➔ шкала УДАР / FAST («Золотой час»)
     - Острый коронарный синдром / инфаркт миокарда ➔ экстренный покой и вызов 103
     - Удушье / инородное тело ➔ прием Геймлиха
     - Массивное кровотечение ➔ прямое давление и наложение жгута
     - Анафилактический шок / отек Квинке ➔ введение адреналина
   - Прямая кнопка вызова экстренных служб (`103 / 112`).

3. **🖼️ Интерактивные визуальные схемы и манипуляции (SVG)**
   - Векторные анатомические иллюстрации высокого разрешения:
     - **Измерение пульса**: лучевая и сонная артерия, правильное положение 2-х пальцев, таймер на 30 сек.
     - **СЛР (Сердечно-легочная реанимация)**: положение рук в замке, центр грудины, глубина 5-6 см, встроенный **звуковой метроном на 110 BPM** с визуальным пульсатором!
     - **Прием Геймлиха**: положение кулака над пупком, вектор толчков вверх и вглубь, самопомощь о спинку стула.
     - **Тест УДАР / FAST**: 4 иллюстрированных шага выявления инсульта.
     - **Остановка кровотечения**: наложение жгута на 5-7 см выше раны, правила фиксации времени.
     - **Ожоги**: охлаждение чистой водой 15-20°C 15-20 минут, строгий запрет масла, жира и спирта.
     - **Боковое восстановительное положение (Recovery position)**: фиксация дыхательных путей при потере сознания.
     - **Анафилаксия**: техника внутримышечной инъекции автоинъектора адреналина в бедро под углом 90°.
     - **Протокол RICE**: покой, холод, компрессия, приподнятое положение при травмах и растяжениях.
     - **Измерение давления**: положение манжеты тонометра на 2-3 см выше локтя на уровне сердца.

4. **⚡ Сверхбыстрая работа и отказоустойчивость**
   - Потоковый стриминг ответа (Server-Sent Events, SSE) — первые токены выводятся без задержки.
   - Двойной контур отказоустойчивости: поддержка внешних OpenAI-совместимых API (DeepSeek, OpenRouter, Cerebras, Chutes) + встроенный мгновенный клинический движок EBM Expert Engine (0 мс задержки даже при сбоях внешних провайдеров).
   - Ключ безопасности хранится строго на сервере в `.env` и никогда не утекает в браузер.

## 🚀 Быстрый запуск

### 1. Запуск одной командой
```bash
python run.py
```
Сервер запустится по адресу: **http://localhost:8000** (или `http://127.0.0.1:8000`).

### 2. Настройка API-ключа и провайдера
Ключ и параметры модели можно настроить:
- Либо через файл `backend/.env`:
  ```env
  LLM_API_KEY=ваш_ключ
  LLM_BASE_URL=https://api.deepseek.com/v1
  LLM_MODEL=deepseek-chat
  ```
- Либо прямо в интерфейсе сайта через кнопку **⚙️ Настройки** в правом верхнем углу.

## ⚖️ Медицинский дисклеймер
*Сервис разработан в строгом соответствии с клиническими стандартами доказательной медицины (EBM) в информационных и образовательных целях, а также для экстренной доврачебной самопомощи. Он не заменяет очного медицинского осмотра и постановки диагноза сертифицированным врачом. В ситуациях угрозы жизни незамедлительно вызывайте скорую медицинскую помощь по номерам 103 или 112.*
