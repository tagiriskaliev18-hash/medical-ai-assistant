# 🩺 «ИИ Доктор» — Клинический ассистент врача приемного покоя и терапевта (EBM)

Интеллектуальная система поддержки врачебных решений (СППР) и экстренной помощи на основе принципов **Доказательной Медицины (Evidence-Based Medicine, EBM)**, клинических рекомендаций (МЗ РК, МЗ РФ, ESC 2024, KDIGO 2021/2024, BTS, ERC 2021, AHA) и мета-анализов Cochrane Library.

Специализированный инструмент для **дежурного врача приемного отделения, терапевта, врача общей практики (ВОП) и ординатора**, решающий ключевую проблему перегруженных дежурств: мгновенная маршрутизация пациентов, исключение острой хирургической и сосудистой патологии, точный расчет дозировок и калькуляторов без галлюцинаций ИИ, а также автоматическое формирование юридически выверенных протоколов осмотра (SOAP) для медицинских информационных систем (КМИС, Дамумед, ЕМИАС).

Приложение работает по **гибридной архитектуре**:
- **100% автономный PWA-клиент** — работает прямо в браузере или на смартфоне без интернета (Service Worker предкэширует все базы, формулы и схемы).
- **FastAPI Backend (опционально)** — локальный микросервис для безопасного проксирования нейросетей, валидации формул и интеграции.

## 🌟 Врачебный функционал (Medical Skills Hub)

### 1. 🧮 Детерминированные клинические калькуляторы (EBM)
> **Критическое правило безопасности:** Нейросеть **никогда** не вычисляет формулы самостоятельно в уме. Все расчеты выполняются строгим математическим кодом на клиенте и бэкенде:
- **СКФ по формуле CKD-EPI 2021 (race-free)**: золотой стандарт KDIGO 2021/2024. Автоматическая стадия ХБП (G1–G5), пересчет по креатинину сыворотки (мкмоль/л), оценка риска контраст-индуцированной нефропатии перед КТ и коррекция доз антибиотиков и НОАК.
- **Шкала CURB-65 (BTS Guidelines)**: объективная стратификация тяжести внебольничной пневмонии (C — сознание, U — мочевина, R — ЧДД, B — АД, 65 — возраст), процент 30-дневной летальности и четкая маршрутизация (амбулаторно / отделение / ОРИТ).
- **Шкала CHA₂DS₂-VASc (ESC Guidelines 2024)**: оценка риска тромбоэмболий при фибрилляции предсердий и четкие показания к ПОАК (Апиксабан, Ривароксабан, Дабигатран).
- **Шкала комы Глазго (GCS, ATLS)**: раздельная оценка E, V, M. Автоматический алерт при $GCS \le 8$ баллов — прямое показание к экстренной интубации трахеи и переводу на ИВЛ.

### 2. 🧪 Лабораторный интерпретатор дежуранта & Синдромальный анализ
Автоматический скрининг острых патологических синдромов по показателям экстренной лаборатории (*Cito!*):
- **Острое повреждение миокарда / ОКС**: детекция тропонина I/T ($\ge 0.04$ нг/мл), алгоритм действий (ЭКГ в 12 отведениях, ДАТТ, катетер, кардиореанимация).
- **Тромбоэмболический синдром (ТЭЛА / ТГВ)**: скрининг D-димера ($> 0.5$ мкг/мл FEU) и рекомендации по шкале Wells и КТ-ангиографии.
- **Острый панкреатит**: скрининг гиперамилаземии ($> 1.5–3\times$ нормы) в сочетании с абдоминальной болью.
- **Острое бактериальное воспаление / СВР / Сепсис**: связка лейкоцитоза, палочкоядерного сдвига ($> 6\%$) и СРБ ($> 10$ мг/л).
- **Электролитные катастрофы**: гиперкалиемия ($> 5.1$ и $> 5.5$ ммоль/л — риск асистолии, введение 10% кальция глюконата), гипокалиемия, тяжелая анемия ($< 70$ г/л — гемотрансфузия), азотемия ($> 115$ мкмоль/л).

### 3. 💊 Экстренная фармакотерапия и проверка DDI (межлекарственных взаимодействий)
- **Справочник дозировок дежурного шкафа**:
  - *Эпинефрин (Адреналин)*: 0.5 мг В/М в переднебоковую поверхность бедра при анафилаксии (**вводится ДО гормонов и антигистаминных!**). 1 мг В/В при СЛР.
  - *Магния сульфат 25%*: 5–10 мл В/В ОЧЕНЬ медленно (за 10–15 минут!). Антидот — Кальция глюконат 10% В/В.
  - *Каптоприл 25 мг*: сублингвально при неосложненном кризе. Жесткое правило: снижение АД не более чем на 20–25% за первые 1–2 часа (профилактика ишемического инсульта).
  - *Моксонидин 0.2/0.4 мг*: криз с симпатикотонией и тахикардией.
  - *Кеторолак 30 мг*: **СТРОГО ЗАПРЕЩЕНО вводить при абдоминальной боли ДО осмотра хирургом** (риск смазывания клиники «острого живота»).
  - *Дротаверин 40–80 мг*: спазмолитик при коликах.
  - *Дексаметазон 4–16 мг*: отек Квинке, астматический статус.
  - *ДАТТ (Аспирин 300 мг разжевать + Клопидогрел 300 мг)*: нагрузочные дозы при ОКС.
- **DDI-чекер (Drug-Drug Interactions)**: мгновенная проверка несовместимых комбинаций:
  - Ингибиторы АПФ + Спиронолактон ➔ риск фатальной гиперкалиемии.
  - НПВП + Антикоагулянты ➔ многократный рост риска тяжелых ЖКТ-кровотечений.
  - Нитроглицерин + Ингибиторы ФДЭ-5 (Силденафил) ➔ катастрофический кардиогенный коллапс (абсолютное противопоказание в течение 24–48 ч).
  - Бета-блокаторы + Верапамил ➔ риск полной AV-блокады и асистолии.
  - Макролиды + Статины ➔ рабдомиолиз и миоглобинурийный нефроз.

### 4. 📝 Генератор клинического осмотра дежуранта (SOAP / КМИС / Дамумед)
Автоматическая компиляция юридически выверенного структурированного протокола первичного осмотра по международному формату **SOAP**:
- **[S] Subjective**: детализированные жалобы, анамнез заболевания (время начала, триггеры) и анамнез жизни (ХНИЗ, аллергоанамнез).
- **[O] Objective**: витальные показатели (АД, ЧСС, SpO2, ЧДД), статус легких и живота.
- **[A] Assessment**: предварительный клинический диагноз с кодом МКБ-10 (встроенная база экстренных нозологий: I10, I11.9, I20.0, I21.9, I26.9, I48, I63.9, J18.9, K35.8, K85.9, N23, T78.2 и др.).
- **[P] Plan**: пакет экстренной диагностики, неотложная терапия в приемном покое и маршрутизация (ОРИТ / профильное отделение / амбулаторно).
- Копирование в буфер одной кнопкой для мгновенной вставки в электронную карту пациента.

### 5. 🚨 Доврачебная помощь, триаж Red Flags и схемы манипуляций
- Скрининг красных флагов: СЛР, инсульт (FAST), кровотечение, Геймлих, анафилаксия.
- Интерактивный **метроном СЛР на 110 BPM** с визуальным пульсатором.
- Анатомические векторные схемы высокого разрешения (SVG).
- Экстренный экспорт сводки для бригад 103/112 (печать в PDF, буфер обмена, Web Share).
- Голосовое управление (Web Speech API) и синтез речи (TTS) для работы «без рук».

## 🚀 Быстрый запуск

### Вариант 1: Полный запуск с бэкендом (Рекомендуется)
```powershell
python run.py
```
Откройте браузер по адресу: **http://localhost:8000**.

### Вариант 2: Автономный PWA без сервера
Просто откройте `frontend/index.html` в браузере или разверните на GitHub Pages / статический хостинг.
Все калькуляторы, DDI-скрининг, интерпретатор анализов, база МКБ-10, генератор SOAP и протоколы первой помощи работают на 100% автономно без интернета.

## 🧪 Автоматическое тестирование

Проект покрыт всесторонним набором автоматических тестов (11 тестов):
```powershell
python -m unittest tests/test_medical_system.py
```
Проверяются:
- Целостность файлов, отсутствие null-байтов и артефактов кодировок UTF-8.
- Валидность всех клинических JSON-баз (`calculators.json`, `emergency_drugs.json`, `lab_reference.json`, `drug_interactions.json`, `icd10.json`, `red_flags.json`, `procedures.json`).
- Наличие всех SVG-схем манипуляций.
- Точность математических расчетов формул KDIGO CKD-EPI 2021, CURB-65, CHA₂DS₂-VASc, GCS.
- Детекция опасных лекарственных взаимодействий (DDI).
- Детекция синдромов экстренной лаборатории (ОКС, ТЭЛА, панкреатит).
- Безопасность и работоспособность эндпоинтов FastAPI (валидация входных данных, защита от утечки ключей).

## 🔒 Безопасность и защита данных
- **Защита от XSS**: Весь контент от внешних нейросетей строго экранируется перед рендерингом в DOM.
- **Изоляция ключей**: API-ключи пользователей хранятся исключительно в `localStorage` браузера и передаются в бэкенд per-request через заголовок `X-Custom-API-Key`.
- **Защита от SSRF**: Эндпоинты конфигурации защищены от перезаписи `base_url` сторонними клиентами.
